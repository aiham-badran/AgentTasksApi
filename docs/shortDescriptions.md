## ✅ النسخة الإنجليزية

> **AgentTasks API** — a REST backend built for humans and AI agents. Dual auth (JWT + API keys), BYOK for Groq/Google/OpenRouter, natural-language-to-task endpoint, and LLM-friendly structured errors. Live demo + Swagger docs on Render.

**عدد الأحرف:** `252` ✅

## ✅ النسخة العربية

> **AgentTasks API** — واجهة برمجية لإدارة المهام مصممة للبشر ووكلاء الذكاء الاصطناعي. مصادقة مزدوجة، مفاتيح LLM خاصة بك (Groq/Google/OpenRouter)، تحويل النص الطبيعي إلى مهام، وأخطاء منظّمة تفهمها النماذج. عرض حي وتوثيق تفاعلي.
